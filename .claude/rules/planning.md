# Planning

- `docs/PLAN.md` Section 19 is the task list. Split every phase into tasks, each a
  checkbox: `- [ ] task`. Tick `- [x]` in the same commit that completes the task.
- Group a phase's tasks under the branch that delivers them (see git-workflow.md).
- Each phase keeps its "done when" line; tick the phase only when that check passes.
- Do not reopen decisions in Section 23. New questions go in Section 24.
- Use the `phase-plan` skill to produce or revise a phase breakdown.
